# The Darkness — Xbox 360 Achievement Tracker

A standalone, mobile-friendly HTML tracker for Heart of Gold, six Darkling outfits, and 27 Underworld letters.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and `README.md` to its main branch.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, **main**, **/(root)**, and save.
5. Open the published GitHub Pages URL.

## Progress
Checkboxes are saved using browser localStorage. This is per browser/device, not synced between devices. Use **Export progress** and **Import progress** to transfer progress.

## Note
The route is adapted from the conversation's draft checklist. Some location details have not been independently verified against a primary walkthrough; check especially missable locations against an established guide before advancing chapters.
